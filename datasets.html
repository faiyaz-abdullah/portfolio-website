  • [D1]EACL 2027

    TIDE

    Benchmarking Large Language Models on Temporally Evolving Document Understanding

    Hugging Face · Temporal QA, Evolving Documents, Code-Mixed Text, Benchmark · Released with EACL 2027

    • dataset
    • code
    • paper
    About
    A benchmark for temporally evolving documents. Because the documents are amended and replaced over time, each question is tied to a date, and answering it means finding the version in force on that date.
    Size
    3,050 question–answer pairs
    Source
    644 official customs instruments issued by the Government of Bangladesh, 1969–2025
    Tasks
    8 task types
    Documents
    Deeply code-mixed, with varied layouts and dates in two calendars
    Annotation
    Expert-verified
  • [D2]EMNLP 2026

    BanglaVerse

    A Cultural Benchmark for Multilingual Vision-Language Models Across Bengali Dialects

    Hugging Face · Vision-Language, Multilingual, Cultural Understanding · Released with EMNLP 2026

    • dataset
    • code
    • paper
    About
    A culturally grounded benchmark of how multilingual vision–language models understand Bengali culture across historically linked languages and regional dialects, showing where models succeed at surface-level recognition but fail at cultural reasoning.
    Images
    1,152 manually curated images across 9 domains
    Tasks
    Visual question answering and captioning
    Languages
    4 languages and 5 Bangla dialects
    Size
    ~32.2K artifacts
  • [D3]EACL 2026

    MathMist

    A Parallel Multilingual Benchmark for Mathematical Problem Solving and Reasoning

    Hugging Face · Mathematical Reasoning, Multilingual, Benchmark · Released with EACL 2026

    • dataset
    • code
    • paper
    About
    A parallel multilingual benchmark for mathematical problem solving and reasoning. Problems are aligned across languages, isolating the effect of language from mathematical difficulty and exposing reasoning gaps that appear only outside English.
    Size
    ≈30K aligned question–answer pairs, from 2,890 parallel Bangla–English gold-standard artifacts
    Languages
    13, spanning high-, medium- and low-resource settings
    Evaluation
    Zero-shot, chain-of-thought, perturbated reasoning and code-switched reasoning
  • [D4]CVPRW 2026

    VisText-Mosquito

    A Unified Multimodal Dataset for Visual Detection, Segmentation, and Textual Explanation on Mosquito Breeding Sites

    Mendeley Data · Multimodal, Object Detection, Segmentation · Released with CVPRW 2026

    • dataset
    • code
    • paper
    About
    Three tasks over mosquito breeding sites in one dataset: object detection, segmentation, and natural-language reasoning about why a site is a breeding risk, so models are evaluated on perception and justification together.
    Detection
    1,828 annotated images
    Segmentation
    142 images of water surfaces
    Explanations
    A natural-language explanation linked to each image

  • [D7]IEEE Access

    JailbreakTracer Corpus

    Datasets for Toxic Prompt and Forbidden Question Classification

    Kaggle · LLM Safety, Prompt Classification, Synthetic Data, Toxicity Detection · Released with IEEE Access

    • dataset
    • code
    About
    The JailbreakTracer Corpus contains two curated datasets for analyzing and classifying prompts that aim to bypass the safety mechanisms of large language models (LLMs).
    Toxic Prompt Classification
    16,029 non-toxic and 1,952 toxic prompts initially; after synthetic augmentation with GPT, 37,333 toxic and 16,053 non-toxic prompts, addressing class imbalance for training LLM safety classifiers
    Forbidden Question Reasoning
    Reasoning-based classification of unethical prompts across 13 categories, including Hate Speech, Malware, Economic Harm, Pornography and Legal Opinion
    Samples per class
    8,250 in the Forbidden Question Reasoning Dataset, for balanced multi-class modeling
